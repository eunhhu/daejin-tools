# 도서관 시간표·예약 사용 안내

> 이 웹 앱은 학교 또는 도서관의 공식 서비스가 아닌 비공식 편의 도구입니다. 공식 정책,
> 예약 내역, 취소, 입실 시작은 도서관 공식 사이트와 앱에서 확인하세요.

## 1. 로그인

1. `/login`에서 본인의 학교 아이디와 비밀번호를 입력합니다.
2. 로그인에 성공하면 현재 계정이 마스킹된 형태로 화면 상단에 표시됩니다.
3. 비밀번호는 로그인 요청에만 사용하고 저장하지 않습니다.

각 브라우저 로그인은 개별 세션입니다. 같은 계정을 다른 브라우저에서 사용해도 시간표 캐시,
예약 준비 티켓, CSRF 토큰, 중복 제출 방지 기록을 공유하지 않습니다. 8시간 동안 사용하지 않거나
도서관 로그인이 만료되면 해당 브라우저만 로그인 화면으로 돌아갑니다.

## 2. 시간표 보기

- 날짜는 한국 시간 기준 오늘부터 7일 안에서 선택합니다.
- 시설 종류와 이용 인원 필터는 이미 받은 결과에만 적용되며 학교 요청을 추가하지 않습니다.
- **새로고침**은 선택한 날짜를 다시 확인합니다.
- 초록 칸은 예약 시작을 선택할 수 있다는 뜻입니다. 전체 이용 구간이나 최종 예약 성공을 뜻하지
  않습니다.
- 물음표는 확인하지 못한 호실이며 빈자리로 보지 않습니다.

날짜별 결과는 세션 안에서 60초 동안 사용합니다. 새 조회는 세션당 시간당 60묶음까지이며 실제
학교 요청 실패 뒤에는 15초 동안 기다립니다. 실패 전에 받은 결과는 최대 5분까지 이전 결과라는
표시와 함께 보여 줄 수 있습니다.

## 3. 예약하기

1. 초록 시작 시간 버튼을 누릅니다.
2. 종료 시간 타임라인에서 버튼을 고릅니다. 각 버튼에는 시작 시각부터 계산한 이용 시간이 함께
   표시됩니다.
3. 사용 목적은 선택 사항입니다. 입력한다면 최대 300자입니다.
4. 호실과 시간을 다시 확인하고 확인 체크를 선택합니다.
5. **예약 확정**을 한 번 누릅니다.

시간 칸을 열거나 종료 시간을 고르는 것만으로는 예약되지 않습니다. 서버는 공식 내역 확인,
사전 검사, 한 번의 예약 처리, 공식 내역 재확인을 순서대로 수행합니다. 결과를 확정할 수 없으면
공식 예약 내역을 확인하기 전 같은 날 다른 예약을 제출하지 마세요.

## 4. 로그아웃과 만료

화면 상단 **로그아웃**을 누르면 현재 브라우저 세션의 도서관 연결, 캐시, 예약 준비 정보,
중복 제출 방지 기록을 정리합니다. 다른 브라우저 세션에는 영향을 주지 않습니다. 만료 안내가
나오면 로그인 화면에서 다시 로그인하세요.

## 5. 운영

```bash
python -m pip install -r apps/library/requirements.txt
export DAEJIN_LIBRARY_STATE_DIR=/absolute/private/runtime-directory
export DAEJIN_LIBRARY_PUBLIC_ORIGIN=https://your-private-host.example
python -m uvicorn apps.library.web:create_app --factory --host 127.0.0.1 --port 18764 --workers 1
```

- 기존 HTTPS 프록시 뒤에서만 사용합니다. 앱 포트는 루프백에만 바인딩합니다.
- `DAEJIN_LIBRARY_PUBLIC_ORIGIN`은 경로 없는 정확한 HTTPS 원본 하나여야 합니다.
- `DAEJIN_LIBRARY_STATE_DIR`에는 세션별 예약 중복 방지 기록만 생기며 비밀번호는 저장되지 않습니다.
- 프로덕션은 반드시 `--workers 1`로 실행합니다.
- 실제 학교 동작 검증은 공식 화면에서 사용자가 직접 확인하며 자동화 테스트는 합성 응답만 사용합니다.
