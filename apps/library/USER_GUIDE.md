# 도서관 시간표·바로 예약 사용설명서

> 비공식 개인용 도구입니다. **연결된 운영자 본인 계정으로 예약**됩니다.
> 다른 사람에게 페이지를 공개하거나 계정을 공동 사용하지 마세요.

## 1. 빈 시간 찾기

1. 시간표 페이지에 접속합니다. 첫 조회에서 호실별 시작시간을 모읍니다.
2. 날짜와 시설 종류를 고릅니다. 인원 필터는 **수용 인원이 맞는 방을 찾는 용도**이며 참여자 등록이 아닙니다.
3. 초록색 **가능** 칸을 누릅니다.

- **초록:** 공식 화면에서 선택할 수 있는 시작시간입니다. 원하는 길이의 전체 구간을 보장하지 않습니다.
- **회색:** 현재 선택할 수 없습니다. 예약·휴실·운영시간·계정 제한 중 이유를 단정하지 않습니다.
- **물음표:** 해당 호실 정보를 확인하지 못했습니다. 빈자리로 취급하지 않습니다.
- **이전 결과 경고:** 표시된 조회 시각의 과거 데이터입니다. 최신 예약 가능 여부와 다를 수 있습니다.

조회는 접속·날짜 변경·수동 새로고침 때만 일어납니다. 시설·인원 필터는 추가 조회를 하지 않습니다.
날짜를 지웠다면 새 날짜를 선택하거나 **오늘**을 누르면 됩니다.

## 2. 클릭해서 예약하기

1. 원하는 호실의 **가능** 칸을 누릅니다. 이 단계는 **예약 준비 조회만** 하며 실제 예약하지 않습니다.
2. 해당 시작시간에 대해 도서관이 반환한 **종료 시간**을 선택합니다. 종료 시각을 임의로 만들지 않습니다.
3. **사용 목적**을 1~300자로 입력합니다. 필요한 내용만 입력하고 불필요한 개인정보는 적지 마세요.
4. 호실·날짜·시작/종료 시간과 계정 안내를 확인하고 확인란을 체크합니다.
5. **예약 확정**을 누릅니다. 이때 도서관에 사전 검증과 실제 예약 요청을 전송합니다.
6. 결과를 확인합니다.
   - **예약 확인 완료 + 내역 번호:** 공식 예약 내역에서 같은 호실·날짜·시간의 `예약중` 항목을 확인했습니다.
   - **예약되지 않았어:** 도서관 사전 검증에서 거절되었습니다. 표시된 이유를 확인합니다.
   - **결과 미확인 / 완료로 확인되지 않음:** 통신 중단 등으로 확정할 수 없습니다. **다시 예약하지 말고 공식 예약 내역부터 확인**합니다.

예약 준비는 **2분** 동안만 유효합니다. 만료되면 창을 닫고 시간 칸부터 다시 선택합니다.
연속 클릭은 한 번만 처리합니다. 제출 결과가 불확실하면 서버를 재시작하더라도 저장된 중복 방지 기록으로 **당일의 새 예약 제출도 차단**합니다. 종료 시간이나 호실을 바꿔도 미확인 제출이 남아 있으면 새로 보내지 않습니다.

이 버전은 공식 양식에서 추가 참여자 입력을 요구하지 않는 경우의 본인 예약을 지원합니다.
추가 참여자·별도 양식·대여 물품 선택이 필요하면 **공식 상세 화면**에서 진행합니다.
도구에서 수용 인원 필터를 바꿔도 다른 사람의 이름·학번이 등록되지는 않습니다.
예약 후 시간표는 자동 재조회하지 않습니다. 필요할 때 직접 새로고침합니다.

## 3. 예약한 뒤 꼭 할 일

도서관 공식 안내 기준:

- 세미나실·캐럴·소강당을 합해 **1일 1회, 최대 3시간** 이용 가능합니다. 연장은 불가합니다.
- 예약은 교외에서도 가능하지만, 입실 처리는 다릅니다.
- **예약 시작 20분 이내**, 해당 실에서 **도서관 Wi-Fi**에 연결한 뒤 공식 도서관 앱의 예약 내역에서 **시작**을 눌러야 합니다.
- 시작 처리하지 않으면 예약이 자동 취소될 수 있습니다.
- 이 도구는 교내 Wi-Fi 확인을 대체하지 않고, 시작·취소·연장 요청도 자동 실행하지 않습니다.

[공식 예약 안내](https://library.daejin.ac.kr/seminar_intro.mir) · [공식 예약 내역](https://library.daejin.ac.kr/seminar_use_history_list.mir)

이용시간·휴실·학교 정책은 바뀔 수 있으며 실제 공식 안내가 우선입니다.

## 4. 오류가 났을 때

**로그인 만료 / 세션 연결 필요**
운영자가 도서관에 정상 로그인해 비공개 세션 파일을 갱신해야 합니다. 도구는 비밀번호를 저장하거나 자동 로그인·세션 연장을 하지 않습니다. 조회 실패 쿨다운은 최대 5분이며 자동 재시도하지 않습니다.

**더 이상 가능하지 않은 시간 / 당일 예약이 이미 있음**
확정 직전 다른 예약이 들어왔거나 계정별 이용 제한일 수 있습니다. 예약 버튼을 반복해서 누르지 말고 공식 내역과 선택 조건을 확인합니다.

**요청 한도**
시간표는 5분 캐시, 새 조회 묶음 사이 최소 30초, 시간당 최대 6묶음입니다. 예약 준비와 확정 확인 요청은 각각 시간당 12회로 제한합니다. 제한은 단일 서버 프로세스 기준이며 여러 창에서도 공유합니다.

**제출 결과 미확인**
HTTP 성공만으로 예약 성공이라 하지 않습니다. 공식 내역을 직접 확인하고, 예약이 있는데 중복 신청하지 않도록 주의합니다. 임의로 중복 방지 기록을 지우거나 재시작으로 제한을 초기화하지 마세요.

## 5. 설치·운영 안내

저장소 루트에서 실행합니다. Node는 테스트에만 필요하고 실제 웹 앱은 Python만 사용합니다.

```bash
python -m pip install -r apps/library/requirements.txt
export DAEJIN_LIBRARY_SESSION_FILE=/absolute/private/path/library-session.json
chmod 600 "$DAEJIN_LIBRARY_SESSION_FILE"
python -m uvicorn apps.library.web:create_app --factory --host 127.0.0.1 --port 18764 --workers 1
```

- 실행한 **그 컴퓨터**의 `http://127.0.0.1:18764/`에서 사용합니다. 다른 기기에 이 주소를 보내도 접속되지 않습니다.
- 페이지 상단 **사용설명서** 또는 `/manual`에서 이 문서를 볼 수 있습니다.
- 세션 JSON은 정상 로그인한 본인의 도서관 쿠키만 보관하는 CDP 형식 배열입니다. `name`, `value`, `domain`, `path`를 사용하며 정확한 도서관 도메인만 전달합니다.
- 세션 파일 옆에 `library-booking-state.json`이 생깁니다. 목적·비밀번호는 이 파일에 저장하지 않으며 예약 결과와 중복 방지 상태를 기록합니다. 둘 다 비공개 파일이며 Git에 올리지 않습니다.
- Windows는 환경변수에 PowerShell 문법을 사용하고 파일 ACL을 본인으로 제한합니다.
- 반드시 **단일 계정·단일 프로세스·로컬 바인딩**을 유지합니다. 이 버전에는 공용 서비스용 계정 로그인·권한 분리가 없습니다. CSRF/Host 검증은 공용 서비스 인증의 대체물이 아닙니다.
- 수강신청 자동조회 서비스와는 별개이며 이 앱을 실행해도 수강 옵저버가 켜지지 않습니다.

## 6. 검증 범위

공식 화면의 호실·시작시간, 종료시간 조회 형식, 사전 검사→예약 처리 흐름, 실제 기존 예약 내역의 파싱을 확인했습니다.
예약 생성·중복 클릭·통신 실패·재시작 이후 중복 방지·거절·CSRF 검사는 **명시적인 합성 응답**으로 테스트합니다.
**개발 검증용으로 실제 학교 예약을 새로 만들거나 기존 예약을 취소하지 않았습니다.** 따라서 실제 학교의 최종 신규 예약 성공은 별도 실사용 확인 범위입니다.
