# 도서관 빈자리 시간표

대진대학교 도서관 예약실의 **선택 가능한 시작 시간**을 호실별 시간표로 모아 보여 주는
비공식 편의 웹 앱입니다. 세미나실·캐럴·소강당, 날짜, 이용 인원으로 좁혀 보고 예약 가능한
칸을 누르면 종료 시간과 최종 내용을 확인한 뒤 예약할 수 있습니다. 취소와 입실 시작은 공식
앱에서 직접 합니다.

사용 방법은 [USER_GUIDE.md](USER_GUIDE.md)에 정리되어 있습니다.

## 개별 학교 계정 로그인

- `/login`에서 각 사용자가 본인의 학교 아이디와 비밀번호로 로그인합니다.
- 서버는 도서관 로그인 페이지 조회 → 로그인 처리 → 세미나실 목록 확인 순서로 인증합니다.
- 비밀번호는 해당 로그인 요청에만 사용하며 파일, 세션 객체, 예약 기록, 응답에 저장하지 않습니다.
- 잘못된 계정 정보는 아이디 존재 여부를 구분하지 않는 동일한 오류로 응답합니다.
- 로그인 요청에는 길이 제한, 동일 출처 CSRF 검사, 요청 횟수 제한이 적용됩니다.

## 서버 세션과 격리

로그인에 성공하면 브라우저마다 256비트 이상의 무작위 세션 토큰을 발급합니다. 쿠키는
`HttpOnly`, `Secure`, `SameSite=Lax`, `Path=/`이며 유휴 상태가 8시간 이어지면 만료됩니다.

각 브라우저 세션은 다음 상태를 다른 세션과 공유하지 않습니다.

- 도서관 쿠키가 든 인메모리 HTTP 클라이언트
- 시간표 캐시와 조회 제한 기록
- 예약 준비 티켓과 확정 제한 기록
- CSRF 토큰과 직렬화 잠금
- 세션별 중복 제출 방지 기록 경로

같은 학교 계정으로 두 브라우저에서 로그인해도 캐시, 티켓, 기록은 서로 분리됩니다. 한 세션의
도서관 로그인이 만료되면 그 세션만 닫고 로그인 화면으로 돌아갑니다. 로그아웃, 유휴 만료,
애플리케이션 종료 시 해당 HTTP 클라이언트와 임시 예약 기록을 정리합니다.

## 조회 의미와 요청 제한

- 초록: 원본 `start_time` 목록에 있는 시작 시간입니다. 전체 이용 가능 구간이나 예약 성공을
  보장하지 않습니다.
- 회색: 원본에서 선택할 수 없는 시간입니다. 예약, 휴실, 운영 시간, 계정 제한 중 이유를
  추정하지 않습니다.
- 물음표: 해당 호실을 확인하지 못한 상태이며 빈자리로 취급하지 않습니다.
- 지난 시각은 비활성화하며 모든 시간은 `Asia/Seoul` 기준입니다.

학교 조회는 사용자가 페이지를 열거나 날짜를 바꾸거나 새로고침할 때만 시작합니다. 세션마다
날짜별 60초 캐시, 최대 5분의 이전 결과, 시간당 60개 새 조회 묶음을 사용합니다. 실제 학교
요청이 실패한 뒤에만 15초 동안 새 조회를 쉬며, 캐시 응답은 시간당 한도에 포함하지 않습니다.
한 세션 안의 학교 요청은 한 번에 하나씩 실행되지만 서로 다른 세션은 동시에 처리할 수 있습니다.

## 예약 안전장치

- 시작 시간을 누르면 상세 화면과 종료 시간만 준비하며 아직 예약하지 않습니다.
- 종료 시간은 버튼형 타임라인으로 표시하고 시작 시각부터의 이용 시간을 함께 보여 줍니다.
- 사용 목적은 선택 사항이며 비워 두면 빈 값으로 전송합니다. 입력할 때는 최대 300자입니다.
- 확인 체크와 **예약 확정**을 거쳐야 한 번의 예약 처리 요청이 전송됩니다.
- 제출 전 공식 예약 내역과 사전 검사 결과를 확인하고, 제출 뒤 공식 내역에서 성공을 다시 확인합니다.
- 결과가 불명확하면 세션별 기록에 남겨 같은 날 추가 제출을 막습니다.

## 실행

저장소 루트에서 설치하고 루프백 주소로 한 프로세스만 실행합니다.

```bash
python -m pip install -r apps/library/requirements.txt
export DAEJIN_LIBRARY_STATE_DIR=/absolute/private/runtime-directory
export DAEJIN_LIBRARY_PUBLIC_ORIGIN=https://your-private-host.example
python -m uvicorn apps.library.web:create_app --factory --host 127.0.0.1 --port 18764 --workers 1
```

`DAEJIN_LIBRARY_STATE_DIR`은 세션별 중복 제출 방지 기록을 잠시 보관할 비공개 디렉터리입니다.
생략하면 시스템 임시 디렉터리 아래를 사용합니다. 자격 증명은 이 디렉터리에 기록하지 않습니다.

브라우저 세션 쿠키가 `Secure`이므로 기존 HTTPS 프록시를 통해 접속해야 합니다. 프록시는 앱과
같은 호스트에서 루프백으로 연결하고, `DAEJIN_LIBRARY_PUBLIC_ORIGIN`에는 사용자가 실제로 보는
단 하나의 HTTPS 원본만 지정합니다. 애플리케이션은 `Host`와 `Origin`을 정확히 검사하며 전달된
사용자 식별 헤더를 신뢰하지 않습니다.

반드시 `--workers 1`을 유지합니다. 여러 프로세스나 복제로 확장하려면 세션 저장소, 잠금,
요청 제한을 공유 저장소로 옮긴 뒤 별도로 검토해야 합니다.

## 검증 범위

파서, 로그인 순서, 세션 격리, 조회 캐시, 예약 준비·확정, 중복 제출 방지, CSRF, 브라우저 UI는
합성 HTML과 `httpx.MockTransport`/가짜 객체로 테스트합니다. 테스트는 실제 학교 로그인이나
예약·취소 요청을 만들지 않습니다.
